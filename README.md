## 💡 Sobre o Projeto
Este projeto foi desenvolvido como **atividade prática** para o curso técnico de **Análise e Desenvolvimento de Sistemas** do SENAC.

Trata-se de um sistema simples para **cadastro e gerenciamento de filmes**.

### Funcionalidades
O sistema permite ao usuário:

* **Cadastrar Filmes:** Inserir o **nome**, a **data de lançamento** e a **categoria** de novos filmes no banco de dados.
* **Visualizar e Buscar:** Exibir todos os filmes cadastrados em uma tabela, com funcionalidade de **busca dinâmica por categorias**.
* **Gerenciar Dados:** Realizar a **edição (atualizar)** e **exclusão** de filmes existentes.
* **Usabilidade:** Possui um botão para **limpar os campos** do formulário, otimizando o uso das funções de cadastro e atualização.
